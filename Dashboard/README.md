# Job Dashboard Theme

This is a custom WordPress theme designed for managing job listings and resumes.

## Features

- Employer Dashboard: Allows employers to create and manage job listings.
- Job Seeker Dashboard: Allows job seekers to create and manage resumes.
- Custom post types for job listings and resumes.
